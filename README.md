# Draggable Lists 可拖拽列表
Higher version of the draggable list mod. This mod makes it so resource packs and servers are draggable because who loves pressing buttons repeatedly just to move an item in a UI.

可拖拽列表模组的高级版本。这个模组让资源包和服务器可以拖拽，谁会喜欢为了移动 UI 中的物品而反复按按钮呢。
